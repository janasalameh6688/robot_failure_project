MODULE 26 — NLP PREPROCESSING AND TRANSFORMERS

**1. Text preparation**

The AI4I 2020 dataset contains numerical sensor measurements rather than natural-language maintenance notes. To demonstrate NLP, I converted each machine record into a text description containing its machine type, air temperature, process temperature, rotational speed, torque, and tool wear.

**2. Tokenization**

Tokenization splits text into smaller units called tokens. I implemented a basic Python tokenizer using regular expressions. For the example machine description, it produced 29 tokens.

This tokenizer is a simple demonstration. It splits decimal numbers such as 298.1 into separate tokens, 298 and 1.

**3. TF-IDF representation**

I used scikit-learn's TfidfVectorizer to transform the 10,000 machine descriptions into numerical feature vectors. The resulting matrix contains 10,000 records and 1,214 text features.

TF-IDF assigns weights based on how frequently a term appears in a document and how informative it is across the document collection. It is a numerical text representation, not a contextual transformer embedding.

**4. How transformers work**

Transformers are neural network architectures used in modern language models. They process token representations using self-attention, allowing the model to consider relationships between tokens in a sequence.

A typical transformer language-processing workflow includes:
- Tokenization: split text into model-specific tokens.
- Embedding: map tokens to learned numerical vectors.
- Positional information: represent the order of tokens.
- Self-attention: calculate how tokens relate to other tokens.
- Neural network layers: refine token representations to support a task.

**5. TF-IDF versus transformer embeddings**

TF-IDF represents terms using statistical weights and does not inherently understand contextual meaning. Transformer embeddings are learned numerical representations that can capture contextual relationships.

**6. Project relevance**

The current AI4I dataset does not contain original maintenance notes. The generated descriptions provide a starting point for NLP experimentation, but they are derived from sensor values rather than real maintenance documentation. A later project stage can use a local Hugging Face tokenizer and model to explore transformer-based text processing.
